Buttons

Pills, 48px tall. One Primary per screen. New: Ghost, Danger, icon, small (toolbars, tables and cards only), loading and disabled states.

.btn + .btn-mint | -ink | -glass | -ghost | -danger · sizes .btn-sm .btn-icon .btn-block · states disabled aria-busy="true" · groups .btn-row .btn-pair

  • Danger only for irreversible actions, always behind a confirm dialog.
  • Ghost for the dismissive action next to a Primary (Cancel, Skip).
  • Icon-only buttons need aria-label; add .tip + data-tip for a hover label.

Links

Inline links in body copy look like this code of conduct; a standalone action link is a text link → and going up a level uses a ← Back to resources.

    Score the demo you saw, not the one you imagined. Ask "what broke?" — it's the most revealing question.

    Code of conduct

    GenAI Genesis is for everyone. We expect every participant, mentor, judge and sponsor to help keep it welcoming and safe.

    • Be kind and assume good intent.
    • Respect people's time, space and work.
    • Report anything that worries you to an organiser.
    Build boldly, and look out for each other.

    Questions? Email contact@genaigenesis.ca.
